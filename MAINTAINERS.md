# Maintainers

The named maintainer and reviewer roster is **to be confirmed before submission**. The final roster must identify:

- technical lead;
- Stellar/Soroban owner;
- x402 facilitator and conformance owner;
- Bazaar/MCP owner;
- QA, DevOps, and security owner;
- project representative for SCF reporting.

Each entry must link verifiable prior work and state post-grant availability. This file intentionally avoids assigning unconfirmed people or overstating Stellar experience.
