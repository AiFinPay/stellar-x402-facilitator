# Support

## Public support

- Usage questions and feature requests: GitHub Discussions or issues.
- Confirmed bugs without sensitive details: GitHub issues.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md).
- SCF and ecosystem coordination: Stellar Developers Discord `#scf-general`.

## Support boundaries

No production support commitment exists before the first production release. Planned production service targets, escalation, degraded-mode behavior, and incident communication are defined in [Operations](docs/OPERATIONS.md).
