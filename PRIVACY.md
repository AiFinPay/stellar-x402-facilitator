# Privacy

The project follows data minimization by default.

The facilitator should process only what is necessary to verify and settle a payment. The catalog should index public resource metadata and verifiable seller ownership. Raw private keys, seed phrases, payment secrets, prompts, protected response bodies, and unnecessary personal identifiers must never be collected.

Operational logs must redact authorization payloads and secrets. Retention, deletion, analytics, lawful request handling, and subprocessors are defined in [Data and Privacy](docs/DATA_AND_PRIVACY.md) before production launch.

This document is a technical privacy commitment, not a substitute for a production privacy notice or legal advice.
