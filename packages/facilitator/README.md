# Facilitator package

Planned production service for canonical Stellar x402 verification and settlement.

## Responsibilities

- expose canonical facilitator endpoints;
- delegate Stellar protocol behavior to `@x402/stellar`;
- enforce policy, limits and idempotency;
- isolate signing and publish safe operational telemetry;
- support explicit testnet and pubnet profiles.

No implementation is committed yet. The first code milestone is defined in [the grant plan](../../docs/grant/MILESTONES.md).
